# Overview

Three documents that give you the big picture of the project.

1. **[`about.md`](about.md)** — What the project is, who it is for, what it does,
   current status and scope.
2. **[`tech-stack.md`](tech-stack.md)** — Which technology is used and why
   (with exact versions), plus which dependencies are unused.
3. **[`architecture.md`](architecture.md)** — Folder structure, routing table,
   Redux slices and data flow.

Reading order: **about → tech-stack → architecture**.
