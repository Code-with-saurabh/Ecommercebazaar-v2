# Storefront fonts

Self-hosted Latin subsets of **Manrope** and **Playfair Display** (regular/italic), provided by Google Fonts under the SIL Open Font License. **Material Symbols Outlined** is Google's Apache-2.0 icon font; this build contains the storefront's named glyphs only. Keep the accompanying licenses with redistributed fonts.

Sources: [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope), [Playfair Display](https://github.com/google/fonts/tree/main/ofl/playfairdisplay), [Material Symbols](https://github.com/google/material-design-icons). Add new icon names to the Google Fonts CSS2 `icon_names` subset before using them. System sans/Georgia remain the text fallbacks.
